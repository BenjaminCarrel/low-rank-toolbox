Low-Rank Toolbox Documentation
================================

``low_rank_toolbox`` is a Python library for efficient numerical linear algebra with low-rank matrices.

.. toctree::

Features
--------

* Memory-efficient storage for low-rank matrices
* SVD, QR, and QuasiSVD representations
* Column Subset Selection algorithms (CSSP)
* Krylov subspace methods
* Randomized low-rank approximations
